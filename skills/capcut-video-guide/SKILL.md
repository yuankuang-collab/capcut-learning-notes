# 剪映视频制作指南

当用户询问剪映（CapCut）视频制作、功能操作、学习路径或创作方法时，使用本技能。

## 使用方式

1. 先判断问题类型，再读取对应参考文件（用 `@references/文件名` 引用）：
   - 官网有哪些课程、课程目录、教程清单、官方公布的功能能力 → `@references/course-catalog.md`
   - 具体功能怎么做（关键帧、蒙版、变速、调色、字幕音频、抠像、剪辑工作流） → `@references/techniques.md`
   - AI 成片怎么做（剪映图文成片/AI文字成片、智能成片混剪、DeepSeek+剪映、即梦AI视频生成与数字人） → `@references/ai-video.md`
   - 怎么系统学、按什么顺序练、练习项目、已知限制 → `@references/learning-path.md`
2. 回答时保留资料中的来源标注：【官网事实】【整理】【第三方】。属于【整理】的操作思路要说明是基于课程目录和公开教程归纳、非官方逐字教程；【第三方】的经验值要说明不是官方标准。
3. 界面按钮名称、AI 功能可用性可能随剪映版本变化，提醒用户以本地安装版本为准。
4. 不要编造课程标题、学习次数或功能参数；资料里没有的信息明确说未知。

## 资料来源

剪映官方学习中心 <https://www.capcut.cn/learning>、官网首页 <https://www.capcut.cn/?keyword=P>、巨量学合作课程页、B站图文专栏（<https://www.bilibili.com>，AI 成片步骤）、即梦官网 <https://jimeng.jianying.com>，以及第三方公开教程（已在参考文件中标注来源）。整理日期 2026-11-25，AI 章节更新于 2026-11-26。

## 边界

本技能收录的是文档知识，不包含视频课程原片。需要逐帧教学的场景，给出官网对应课程链接让用户自行观看。
