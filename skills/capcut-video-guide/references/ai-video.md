## 1. 剪映专业版「图文成片 / AI 文字成片」8 步【B站专栏】

来源：B站专栏《剪映专业版图文成片功能一键自动生成视频》，三郎会声会影，2026-06-30。<https://m.bilibili.com/opus/987963325576904725>

1. 草稿页点 **图文成片**（新版叫 **AI 文字成片**）。
2. 输入文案：直接粘贴，或点 **成片助手** 输入想法由 AI 生成。
3. 文案可润色/扩写/缩写；素材选 **智能生成**（按风格）或 **本地上传**（第三方：素材总时长建议 ≤20 分钟）。
4. 选角色：预设公共角色，或「我的角色 → 创建角色」（本地上传 / AI 生图 / 根据文案一键生成）。
5. 点角色小铅笔编辑：换音色、改角色描述后重新生成，满意后保存。
6. 选音乐（可跳过，生成后再加）。
7. 回「画面」选 **智能分镜** 类型与视频比例（16:9 / 9:16）。
8. 点 **生成视频**，等待完成。

- **消耗积分**，无积分不可用。
- 生成后点 **更多编辑** 进多轨道精剪，或直接导出。
- 同作者另一版（AI 文字成片）步骤一致：<http://www.vsx10.com/a/1409.html>【第三方】

## 2. 剪映「智能成片 / 自动剪辑」混剪 5 步【第三方】

来源：<https://www.qishijinka.com/software-testing/64275>、<https://yule.sohu.com/a/1102228845_121876616>

1. 素材全部拖入媒体库，先删废片，按开头/主体/结尾分文件夹。
2. 全选素材 → 右键 **智能成片**。
3. 选比例（抖音9:16、B站16:9）、主题（动感/温馨）、配乐 BGM。
4. 点 **立即生成**，等几分钟到十几分钟出初稿。
5. **人工精修**：删镜头、调顺序、加贴纸/文字、平衡音量。

**实操细节（第1/3/4/5步）**【第三方，今日头条 <https://www.toutiao.com/a7707158656218825266>、<https://www.toutiao.com/a7702100042290708992>】：素材拖进**素材库而非时间线**；先花约10分钟初筛删废帧、按主线情绪排序，量大时用「智能镜头分割」。主题描述框写具体，示例：「生日祝福视频，氛围温馨暖调，节奏前慢后欢快，适配生日主题流行配乐」。AI 初稿会自动排序、裁剪、按节拍配乐。精修时拖动边缘剪废镜头、拖拽调顺序、逐段调色温/曝光、语音识别字幕。

**精修参数（7步指南）**【第三方，微信公众号 <https://mp.weixin.qq.com/s?__biz=MzY5ODQxOTc2Mg==&mid=2247484015&idx=1&sn=0601362c9ae380263edd19a9dcb4e0e2>】：
- 四原则：剪在动作里、声音先过渡、色调统一、节奏有呼吸。
- 切点四匹配：动作匹配（下镜起始帧接上镜动作末尾）、视线匹配、方向匹配、景别递进（全→中→近→特）。
- 转场与节奏：**90% 场景用硬切**；段落切换交叉溶解 **0.5–1 秒**；快节奏 **0.5–1.5 秒/镜头**、慢节奏 **3–8 秒/镜头**；难衔接处加 **1–2 秒空镜**；切点前后各加两帧关键帧轻微缩放 + 音频交叉淡化。
- 声音三层轨：人声分离 / AI 生成 BGM / 音效各一轨；用 J-cut / L-cut 让声音先行；**BGM 在对白时压到两三成音量**。
- 色调：选一段最满意的当**基准片**，其余素材色温/曝光/饱和度向它对齐；智能调色拉基调 + 色相饱和度曲线微调。
- 导出前三遍自检：看画面跳帧 → 戴耳机听爆音与音量配比 → 只听整体节奏；用**后台超清导出**。

**入口名称**（随版本变化）：AI成片 / 文本成片 / 主题成片 / 智能成片 / 一键成片 / 智能剪同款。找不到就更新版本或在软件内搜索；兜底用「文本朗读+识别字幕+智能剪同款」。

**通用提示词模板**：

```
请为【目标受众】制作一条【时长】的【横屏/竖屏】短视频，主题是【视频主题】。
开头3秒用一个问题或反常识结论吸引注意力；正文分为3个部分，每个部分只讲一个重点；
结尾总结并引导观众评论或收藏。整体语气【自然/专业/幽默】，节奏明快，字幕简洁，
优先使用【人物口播/操作画面/相关实拍素材】。
不要出现夸大表述、错误信息、无关画面和明显转场。
```

## 3. DeepSeek + 剪映：脚本到成片【B站专栏】

来源：<https://m.bilibili.com/opus/1033744764985409537>（小达望天涯，2025-02-14）

- **四步提问法**：背景（身份+受众）→ 任务（要什么）→ 要求（风格+重点+分镜）→ 补充（细化场景）。不够详尽就追加需求。
- **素材生成**：把提示词输入可灵/Midjourney 文生图 → 用「图片生成视频」让静图微动；风格不符补细节，人物动作生硬就在剪映叠加动态模糊/缩放。
- **一键成片**：素材拖入时间轴 → 搜模板（如治愈风）自动配乐与转场 → 字幕用手写体、快节奏用0.5倍速、治愈画面慢速+柔光、加 BGM。
- **进阶**：拆任务+交叉验证治 AI 幻觉；脚本加反转；画中画叠实拍；用后台完播率反向优化。

## 4. 即梦 AI：数字人对口型 5 步【B站专栏】

来源：<https://m.bilibili.com/opus/1087413873192992771>（三郎会声会影，2026-04-22）

1. 打开即梦 → 左侧 **生成** → 切换 **数字人**。
2. 点 **角色** → 上传图片或视频（真人或动漫，**需清晰正脸**），也可用即梦生成的素材。
3. 选模型（生成时长均 ≤30 秒）：**大师模式**（仅图片，会员）/ **快速模式**（仅图片）/ **基础模式**（仅视频）。
4. 点 **音频** → 上传音频，或写 ≤120 字文案用即梦生成。
5. 点生成对口型视频。

**消耗积分**随音频时长与文字多少变化。

## 5. 即梦 AI 视频生成【官网】

- **三步生成**（Seedance 2.5，<https://jimeng.jianying.com/tools/seedance-2-5>）：进入 AI 视频工具选模型 → 上传参考图/视频并写提示词（主体、动作、镜头、风格）→ 生成预览并下载。官网强调 4K 输出与四类场景（广告、社媒、影视预演、AI短剧）。
- **AI 短剧新手问答**（<https://jimeng.jianying.com/tools/ai-short-drama>）：先做「一场戏」（一个地点、少量角色、一个冲突）；探索氛围用文生视频、确定造型构图用图生视频；固定角色面容/发型/服装保一致性；提示词按「角色与场景→动作→景别运镜→光线风格」写并说明动作顺序，**不要整集压进一条提示词**；官方明确不承诺一次生成整部/多集。
### 5.1 Seedance 2.0 提示词【官网一手】

<https://jimeng.jianying.com/tools/seedance-2-0>

- **核心公式**：先定义主体与动作，再补充运镜、光线和声音。
- **官网示例原文**：「以参考图中的黑色墨镜为主体，保留镜框轮廓与镜片质感。运用子弹时间特效，让墨镜悬停在空中，镜头缓慢环绕，依次呈现镜片反光、镜腿线条与材质细节。背景香水瓶与珠宝形成有层次的虚化，冷色侧光勾勒产品边缘。随后恢复正常速度，配合转场音效与短促节拍，不添加字幕。」
- **四类参考分工**：文字/图片=构想或参考画面；视频=动作与运镜方向；音频=声音依据；音画联合=声音参与叙事。**每份素材写清用途**。
- **官网上手三步**：定主体场景动作并挑参考 → 选模型描述动作/运镜/光线/声音并确认比例时长积分 → 检查外观/衔接/声音时机，**一次只改一个重点**。
- **FAQ**：可商用（素材需授权）、有免费试用积分、支持音画同步与文/图生视频、人物一致性靠提示词+参考维持；先用清晰短提示词试镜再加细节。

### 5.2 提示词实操细节【第三方】

- 今日头条 <https://m.toutiao.com/w/1857080638300224/>：基础版文生视频（选模型→写场景/动作/风格/镜头/色调→时长约5s、比例3:4、1080p→生成30秒–3分钟）；进阶多模态（首帧图用首尾帧入口、多素材用全能参考入口，最多12个素材，提示词用 `@素材名` 指定用途）。
- 塔猴《即梦视频镜头提示词终极指南》<https://www.tahou.com/article/217569515053592581>：
  - 把提示词当**导演指令**：写「缓缓推近人物含泪的眼眸，背景逐渐虚化」而非只写「推镜头」。解析优先级：主体场景 → 镜头类型方向 → 速度幅度 → 焦段景深 → 光影氛围。每次只选一个核心镜头意图。
  - **参数化**：机位高度 0.3m/1.2m/3m；轨道速度 0.5/1.0/3.5 m/s；焦段 16/35/85mm；旋转 10–20°/s。示例「高机位后拉，机位3m，轨道速度1.0m/s，焦段20mm」。
  - **时间码一镜到底**：「0到3秒从[场景A]缓慢推近，3到6秒右摇进入[场景B]，6到10秒绕主体半圈后拉展示[场景C]全景」，每段一个运动、方向合逻辑。
  - **产品节奏模板**（5–6秒）：0-1s微距推近 → 1-2.5s拉远至全貌(0.6m/s) → 2.5-4s 360°环绕(50mm) → 4-5.5s慢推至logo。
  - **安全组合**：慢推+慢摇 / 跟拍+拉远 / 环绕+轻推；避免超过两个核心运动叠加。
  - **FAQ**：一意图一句话、超三行就拆分；速度失效查面板档位与矛盾指令；首尾帧时提示词定义「过渡方式」；面板预设稳定、提示词灵活可叠加；风格一致用固定模板「[镜头]+[速度]+[焦段]+[主体]+[场景]+[画质]」只换主体场景。

## 6. 工作流选择

| 情况 | 推荐 | 核心动作 |
| -- | -- | -- |
| 有文字没素材，快速出片 | 剪映专业版图文成片/AI文字成片 | 文案→素材风格→角色/配音/分镜→生成→精剪 |
| 有一堆素材要混剪 | 剪映智能成片/一键成片 | 入库→右键智能成片→比例/主题/配乐→生成→精修 |
| 要原创 AI 画面、角色口播、短剧 | 即梦 AI → 剪映 | 写分镜提示词→逐镜生成→数字人口播→导入剪映成片 |

**共性**：AI 做脚本/素材/粗剪等重复劳动；人工把关事实、节奏、字幕、音量与发布标准。AI 成片功能基本都消耗积分，额度以登录后页面为准。

**边界**：第 2 节精修参数与 5.2 节提示词实操细节为第三方经验建议（非官方标准），按钮名、参数与积分规则随版本变化，以本地软件和登录后页面为准；5.1 节为即梦官网一手，但效果仍受素材与版本影响，需自行试镜验证。B站视频课程未逐帧观看，详细步骤取自图文专栏正文与官网。
