## 1. 三幕结构【一手-已核实】

<https://www.studiobinder.com/blog/thr>（Alyssa Maio，2024-12-02）

- 三幕 = **Setup / Confrontation / Resolution**，源头亚里士多德《诗学》beginning-middle-end，Syd Field 1978《Screenplay》确立现代版。
- 量化：第一幕通常前 **20–30 分钟**；剧本约 **20–30 页 / 全片 25%** 处结束。
- K.M. Weiland 八段：Hook → Inciting Event → First Plot Point（不归点）→ First Pinch Point（第二幕约 1/4）→ Midpoint（正中点，"以为搞定却被抽走地毯"）→ Second Pinch Point → Third Plot Point → Climax → Resolution。原文用《侏罗纪公园》逐拍示范。
- Blake Snyder《Save the Cat!》拆成 **15 个 beat**；第二幕本质是**升级 escalation**，直线上升会无聊。
- 心法：结构是指南不是规则，节点从故事有机性出发，不死守页数。

**延伸【仅摘要】**：Script Outline <https://www.studiobinder.com/blog/script-outline-template>——把 beat 扩展成逐场戏的 step outline，用尽可能少的场景连接。

## 2. 分镜构图三维度【一手-已核实】

<https://www.studiobinder.com/blog/storyboard-composition-techniques/>（Kyle DeGuzman，2024-12-18）

- 构图 = 场景元素在画框中的安排 + 摄影机摆放；受机位、调度、镜头、角度、运动共同影响。
- **分镜每格必标三件事**：**Shot size（景别）**、**Shot type（camera height 角度 + framing 视角）**、**Camera movement（运镜）**。
- 景别由机位距离决定，也受焦距影响。
- **角度服务叙事**：俯拍让角色弱势，仰拍让同一角色有权力。
- Framing 决定心理位置：POV、过肩 OTS、单人/双人/三人、insert shot（强调细节）。
- 运镜改变构图：可从 wide 起、push in 收到 close-up；标清 size/angle/framing/movement 别人才还原得了。

**延伸【仅摘要】**：Camera Movement Worksheet PDF <https://s.studiobinder.com/wp-content/uploads/2018/09/Filmmaking-Techniques-Camera-Movement-Worksheet.pdf>——勾选清单（ECU→EWS、eye/low/high/overhead、single/two/OTS/POV、rack/shallow/deep focus、static/pan/tilt/track/pedestal、handheld/gimbal/drone）；每镜先定 "Point of Attention" 再倒推镜头组合。

## 3. J-cut 与 L-cut【一手-未抽查】

- J-cut <https://www.studiobinder.com/blog/what-is-a-j-cut-in-film/>：**下一场声音先于画面出现**，形状像 J。用途：对白中让听者反应有分量、场景转换制造悬念、开场先声夺人、刻意强调（《血色将至》"oil man" 台词先播约 **20 秒**）。操作：下一场音频切进来，上一场画面延续覆盖。选什么声音前置决定观众记住什么。
- L-cut <https://www.studiobinder.com/blog/what-is-an-l-cut-in-film/>：**上一场声音延续到下一场画面**，形状像 L。用途：停留在听者反应镜头、暗示角色想法、旁白蒙太奇、声音带进字幕/黑暗、闪回。声音跨越切点消除生硬感，也能刻意强调；延长多少直接改变感受。

**延伸【仅摘要】**：Transitions Guide <https://www.studiobinder.com/blog/types-of-editing-transitions-in-film/>——contrast cut 靠并置反差；dissolve 常 **24–48 帧（1–2 秒）**；dynamic cutting 是故意让剪辑被看见。
