## 3. 建议学习路径【整理】

1. **入门（照着做）**：先看《零基础剪辑入门》10 节，按“界面 → 素材 → 比例 → 裁剪组合 → 音频 → 字幕贴纸 → 特效滤镜 → 转场动画 → 封面导出”的顺序建立完整工作流概念。
2. **功能补全（查漏）**：以《剪映功能大全》87 节为字典，遇到不会的功能按需查；重点掌握分割、变速、关键帧、蒙版、画中画、文本识别。
3. **进阶（做作品）**：转向专业版课程，练时间线多轨道、关键帧动画、蒙版与混合模式、曲线变速、调色（一级校正 → 二级风格化）。
4. **创作（提质量）**：学习拍摄教学与风格大片分类，把“拍什么/怎么拍”和“怎么剪”一起练；用模板反向拆解轨道结构和特效参数。

## 4. 核心操作知识点速查【整理】

> 以下为基于上述课程目录和公开教程归纳的通用操作思路，不是官网逐字教程；具体按钮名称可能随剪映版本变化。

### 4.1 剪辑工作流

- 新建项目 → 设置画布比例（横屏/竖屏）→ 导入素材 → 粗剪（分割、删除、排序、吸附）→ 精剪（变速、关键帧、蒙版）→ 包装（字幕、贴纸、特效、转场）→ 音频（配音、音乐、音效、淡化）→ 调色 → 封面与导出。
- 分割用于裁掉废弃片段；删除后开启“吸附”让后续素材自动衔接，避免黑场。
- 多轨道逻辑：主轨放主体画面，画中画/贴纸/文字/特效放上层轨道；上层素材可单独调整位置、大小和混合模式。

### 4.2 关键帧

- 作用：让位置、缩放、旋转、不透明度等参数随时间变化，产生推拉镜头、移动字幕、渐显渐隐等动画。
- 操作思路：在参数旁点击关键帧按钮添加起点 → 移动时间线到另一点 → 修改参数 → 自动生成补间动画。
- 常见练习：画面缓慢放大（推镜）、贴纸跟随人物移动、蒙版形状从圆形变矩形。

### 4.3 蒙版与混合模式

- 蒙版控制“显示哪一部分画面”，常见形状有线性、圆形、矩形、钢笔绘制；可调羽化、位置、旋转。
- 混合模式控制上下轨画面如何融合，常用于分屏、双重曝光、文字透底、遮罩转场。
- 注意：做转场时前后镜头要预留足够素材长度，否则转场会被截断。

### 4.4 变速与音画同步

- 常规变速：整段统一倍速；曲线变速：在速度曲线上加减控制点，做“慢—快—慢”等节奏变化。
- 口播类素材变速要处理“保持音调”，否则人声变调；大变速时更稳的做法是先分离音频，只对视频轨变速后重排音频。
- 慢动作卡顿通常与素材帧率不足有关，拍摄时优先用 60fps 以上素材。

### 4.5 文字、音频与字幕

- 字幕可用“识别字幕/智能字幕”自动生成后校对，比逐字手打快；歌词也可自动识别。
- 音频处理：原声、配音、背景音乐、音效分层放置；用淡化让开头结尾自然，用音量/闪避避免盖过人声。
- 音乐版权：官网专门有“如何避免作品音乐侵权”教程，商用前注意授权范围。

### 4.6 调色

- 顺序建议：先校正（曝光、白平衡、对比度）→ 再风格化（滤镜/LUT、HSL、曲线）→ 最后局部调整（蒙版+调节图层）。
- 官网有“HSL调色原理详解”和“剪映AI作图进阶教程”等专题可继续深挖。

### 4.7 AI 功能

- 官网“剪映功能”分类下单列“剪映AI”；首页热门教程包含 AI 作图写真、歌词生成、变声等。
- 常见 AI 能力：智能字幕、智能抠像、图文成片、文本朗读、AI 作图；具体可用功能以当前软件版本为准。

## 5. 实操练习清单【整理】

按顺序完成 5 个小作品，比只看教程更有效：

1. **15 秒卡点视频**：3–5 段素材 + 音乐卡点 + 分割/吸附练习。
2. **旅行 Vlog**：比例设置 + 转场 + 字幕 + 封面导出，复刻《零基础剪辑入门》完整流程。
3. **人物特写**：关键帧推镜 + 蒙版分屏 + 美颜/防抖。
4. **情绪短片**：曲线变速（慢—快—慢）+ 音乐节奏对齐 + 基础调色。
5. **带货/口播短视频**：智能字幕 + 文本朗读/变声 + 贴纸 + 音乐音量与闪避。

复盘方法：每完成一个作品，写出“用了哪个功能、解决什么问题、下次怎么改进”三句话。

### 8.1 官网首页公布的能力全景【官网事实】

来源：剪映官网首页 <https://www.capcut.cn/?keyword=P>，页面原文列出以下能力：

**AI 智能工具**

- 视频/创作：AI文字成片、营销成片、AI音乐、智能解说粗剪、智能剪口播（AI识别无效词，对着文本剪口播）
- 画面：美颜美体（支持单人和多人模式）、超清画质（一键画质修复和增强）、智能抠像（智能识别人像抠除背景）、智能调色、AI补帧（提升帧率）
- 音频：人声分离（提取人声与背景声）、AI音效（智能匹配音效）、音频降噪、人声美化（变磁性/变圆润等）、响度统一（统一至行业标准）
- 其他：数字人（海量形象和声音、支持定制）、文本朗读（热门音色或音色克隆）、智能搜索素材

**专业剪辑能力**

- 蒙版：线性、圆形、文字、钢笔等多种形式，用于创意转场、抠像、局部特效
- 关键帧：设置起点和终点自动生成流畅过渡，支持移动、缩放、淡入淡出
- 调色：色轮、HSL、色相饱和度曲线、浮点调色、RGB曲线
- 多机位：按自动或声音方式对齐，支持 4 机位 / 9 机位模式多角度切换
- 多时间线：一个草稿内创建多条时间线，新增上限 50 条，便于分区剪辑
- 音频剪辑：升降调、声音分离、立体声平衡、音频创作布局

**官网列出的适用场景**：自媒体口播、影视综二创、政企宣传、营销推广、专业剪辑。每个场景对应推荐的功能组合，例如口播用“美颜美体 + 智能剪口播 + 人声美化 + 智能抠像”，专业剪辑用“钢笔蒙版 + 关键帧 + 多机位 + 音频剪辑”。

### 8.2 抠图/抠像的四类方法【第三方，来源见下】

一般教程将抠图分为：智能抠像（背景单一时最快）、色度抠像（绿幕/蓝幕，用取色器+容差）、人像分割（无绿幕，AI识别人体轮廓）、混合模式+蒙版（纯色背景或需保留部分背景时）。参数数值各家经验不同，仅供试验起点，非官方标准。
来源：<https://g.pconline.com.cn/zhizao/article/1418278.html>
